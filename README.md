# 어쩌다 AI — 태원고등학교

성남 태원고등학교 대상 100분 인터랙티브 강의용 one-page 웹앱.

## 구성
- Part I — 어쩌다 나: 직업과 삶의 경로
- Part II — 어쩌다 AI: Turing → Perceptron → Backprop → CNN → AlphaGo → Transformer → Diffusion → ChatGPT → Agent
- Part III — 어쩌다 미래: AI와 직업/업무의 변화
- Part IV — 어쩌다 너: Learn / Ask / Make / Care

## 로컬 실행
정적 사이트이므로 `index.html`을 열거나 간단한 HTTP 서버로 실행하면 됩니다.

```bash
python3 -m http.server 8000
```

## GitHub Pages
저장소 Settings → Pages에서 `main` / root를 선택하면 됩니다.
